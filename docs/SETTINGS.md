# Настройки Timer 3

## Где хранятся файлы

По умолчанию приложение использует:

    %APPDATA%\Timer_3\profiles\user.json

Путь к последнему выбранному профилю хранится отдельно:

    %APPDATA%\Timer_3\active_settings.json

Служебный файл active_settings.json не является пользовательским профилем. Его не нужно выбирать в окне настроек.

## Полный пример профиля

    {
        "version": 1,
        "file_melody": "_internal/default.mp3",
        "voice_interval": 10,
        "beep_interval": 3,
        "beep_period_in_final": 11,
        "restore_time": false,
        "hm_h": 0,
        "hm_m": 0,
        "ms_m": 0,
        "ms_s": 0,
        "active_tab_in_QTabWidget": 0,
        "cycle_intervals": "",
        "cycle_repetitions": 3,
        "cycle_endlessly": false,
        "current_interval": 0,
        "interval_duration": 0,
        "cycle_left": 0
    }

Тот же пример находится в [examples/settings.example.json](../examples/settings.example.json).

## Поля

| Поле | Тип | Допустимые значения | Значение по умолчанию | Назначение |
| --- | --- | --- | --- | --- |
| version | integer | текущая версия схемы | 1 | Версия формата настроек |
| file_melody | string | путь к MP3 | _internal/default.mp3 | Мелодия завершения |
| voice_interval | integer | 1–120 | 10 | Интервал голосовых сообщений, секунд |
| beep_interval | integer | 1–30 | 3 | Интервал финальных сигналов, секунд |
| beep_period_in_final | integer | 1–20 | 11 | Длительность финального периода, секунд |
| restore_time | boolean | true или false | false | Восстанавливать время и цикл при запуске |
| hm_h | integer | 0–23 | 0 | Часы обычного таймера |
| hm_m | integer | 0–59 | 0 | Минуты в режиме часы + минуты |
| ms_m | integer | 0–59 | 0 | Минуты в режиме минуты + секунды |
| ms_s | integer | 0–59 | 0 | Секунды обычного таймера |
| active_tab_in_QTabWidget | integer | 0 или 1 | 0 | Активная вкладка: обычная или циклическая |
| cycle_intervals | string | числа 1–59 через разделители | пустая строка | Интервалы цикла в секундах |
| cycle_repetitions | integer | 1–99 | 3 | Число повторов всего цикла |
| cycle_endlessly | boolean | true или false | false | Бесконечное повторение цикла |
| current_interval | integer | неотрицательное | 0 | Служебное состояние текущего интервала |
| interval_duration | integer | неотрицательное | 0 | Служебное состояние длительности |
| cycle_left | integer | неотрицательное | 0 | Служебное состояние остатка времени |

Поля current_interval, interval_duration и cycle_left зарезервированы для состояния циклического таймера. Пользователю не требуется редактировать их вручную.

## Правила чтения

При загрузке применяется безопасная нормализация:

- неизвестные поля игнорируются;
- отсутствующие поля получают значения по умолчанию;
- числовые строки, например "10", преобразуются в числа;
- boolean не принимается вместо числа, несмотря на особенности типов Python;
- число вне допустимого диапазона заменяется значением по умолчанию;
- cycle_intervals разбирается как последовательность целых чисел от 1 до 59;
- корень JSON должен быть объектом, а не массивом или строкой.

Повреждённый JSON не приводит к аварийному завершению. Storage возвращает безопасный DTO, сохраняет его в активный файл и добавляет предупреждение для интерфейса.

## Пути к мелодии

Допустимы:

- относительный путь к ресурсу проекта, например _internal/default.mp3;
- абсолютный путь к пользовательскому MP3-файлу.

Во время запуска из PyInstaller относительные пути разрешаются относительно временного каталога распакованных ресурсов.

## Переключение профиля

При выборе другого файла приложение:

1. нормализует путь;
2. отклоняет путь, который указывает на каталог;
3. загружает существующий профиль или создаёт новый со значениями по умолчанию;
4. записывает путь в active_settings.json;
5. сохраняет нормализованные значения в выбранный профиль.

Если служебный указатель повреждён или недоступен, используется основной профиль user.json.

## Ручное восстановление

Чтобы вернуться к стандартному профилю:

1. закройте приложение;
2. переименуйте active_settings.json или удалите только этот служебный файл;
3. запустите приложение снова.

Timer 3 выберет profiles/user.json. Удаление пользовательского профиля также допустимо: при следующем запуске он будет создан заново со значениями по умолчанию.
