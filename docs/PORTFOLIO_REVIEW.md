# Состояние проекта для публикации

## Готово

- пакетная структура src/timer_3;
- обычный и циклический режимы таймера;
- точный отсчёт с компенсацией дрейфа;
- голосовые сообщения и финальная мелодия;
- JSON-профили в каталоге пользователя;
- безопасная обработка повреждённых настроек;
- unit- и компонентные тесты логики и UI-связей;
- общий уровень покрытия выше 80%;
- Ruff, mypy, Black и pytest настроены через pyproject.toml;
- Windows CI для compileall, pytest и Ruff;
- PyInstaller spec и сценарий build_exe.bat;
- скриншоты главного окна и настроек;
- пользовательская, архитектурная и разработческая документация.

## Перед публичным релизом

1. Проверить полный запуск на чистой Windows-машине.
2. Собрать приложение через build_exe.bat.
3. Проверить встроенную и пользовательскую мелодию.
4. Проверить голосовой движок Windows.
5. Проверить создание профиля в новом пользовательском аккаунте.
6. Выполнить локальные проверки:

       .venv\Scripts\python.exe -m pytest
       .venv\Scripts\python.exe -m ruff check src tests
       .venv\Scripts\python.exe -m black --check src tests
       .venv\Scripts\python.exe -m mypy src tests

7. Создать тег версии и приложить собранный архив из dist.

## Рекомендуемое описание репозитория

    Windows desktop countdown and interval timer built with Python and PyQt6, with voice notifications, JSON profiles and PyInstaller packaging.

## Не публиковать

- .venv, build, dist, __pycache__ и кэши инструментов;
- рабочие JSON-профили пользователя;
- файлы с абсолютными локальными путями;
- временные аудиофайлы;
- отладочные скриншоты с личными данными.
