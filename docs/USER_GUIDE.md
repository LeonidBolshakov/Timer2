# Руководство пользователя Timer 3

## Назначение

Timer 3 отсчитывает заданное время и сообщает о его окончании звуком. Приложение поддерживает одиночный отсчёт и повторяющиеся последовательности коротких интервалов.

## Запуск

При запуске открывается главное окно с двумя вкладками:

- **Обычный таймер**;
- **Циклический таймер**.

В нижней части окна расположены кнопки **Пуск**, **Выход** и **Настройка**.

Если приложение запускается из исходников:

    .venv\Scripts\python.exe -m timer_3.main

Если используется собранная версия, запустите:

    dist\timer_3\timer_3.exe

## Обычный таймер

### Ввод времени

Доступны две независимые пары полей:

1. **Часы и минуты** — часы от 0 до 23, минуты от 0 до 59.
2. **Минуты и секунды** — минуты и секунды от 0 до 59.

Используйте только одну пару. Когда пользователь начинает ввод в одной паре, поля другой пары очищаются и становятся неактивными для текущего значения.

Примеры:

- 1 час 15 минут: введите 1 и 15 в верхнюю пару;
- 5 минут 30 секунд: введите 5 и 30 в нижнюю пару;
- 45 секунд: оставьте минуты пустыми и введите 45 в поле секунд.

### Запуск и завершение

Нажмите **Пуск**. Кнопка блокируется, раздаётся короткий сигнал и начинается отсчёт.

Во время работы:

- поля времени обновляются каждую секунду;
- через заданный интервал произносится оставшееся время;
- в финальном периоде воспроизводятся короткие сигналы.

При достижении нуля приложение проигрывает выбранную мелодию и закрывается.

## Циклический таймер

Циклический режим выполняет последовательность интервалов несколько раз.

### Задание интервалов

Введите длительности интервалов в секундах. Разделителями могут быть пробел, запятая, точка или точка с запятой.

Примеры:

    30 10 30 10

    20, 5, 20, 5

Каждый элемент должен быть целым числом от 1 до 59. Если строка некорректна, приложение подаст сигнал и вернёт предыдущее значение.

### Число повторов

Поле **Повторов цикла** задаёт, сколько раз будет выполнена вся последовательность.

Например, интервалы 30 10 при трёх повторах выполняются так:

    30 → 10 → 30 → 10 → 30 → 10

Флажок **Повторять бесконечно** отключает ограничение по количеству повторов. Для остановки такого сценария используйте кнопку **Выход** или закройте окно.

### Индикация

Во время работы отображаются:

- номер текущего интервала внутри цикла;
- исходная длительность текущего интервала;
- количество оставшихся секунд.

Между интервалами раздаётся короткий сигнал. После выполнения последнего повтора приложение закрывается.

## Окно настроек

Нажмите **Настройка** в главном окне.

### Голосовые сообщения

**Промежуток между голосовыми сообщениями** задаётся в секундах, допустимый диапазон — от 1 до 120.

Если предыдущее сообщение ещё воспроизводится, следующее пропускается. Это предотвращает наложение речи.

### Финальные сигналы

- **Промежуток между beep** — частота сигналов в финальной части, от 1 до 30 секунд.
- **Период выдачи конечных beep** — за сколько секунд до завершения включаются сигналы, от 1 до 20 секунд.

Например, при промежутке 3 и финальном периоде 11 сигнал прозвучит на остатке 9, 6, 3 и 0 секунд.

### Мелодия завершения

Кнопка выбора рядом с полем мелодии открывает диалог файла. Поддерживаются MP3-файлы.

Если путь пуст или файл невозможно воспроизвести, приложение покажет сообщение об ошибке и завершит работу.

### Восстановление времени

Флажок **При следующем входе восстанавливать время таймера** управляет сохранением введённого времени и параметров циклического режима.

Если флажок выключен, при следующем запуске поля времени и цикла сбрасываются. Остальные настройки, включая интервалы голосовых и звуковых сообщений, сохраняются.

## Профили настроек

Timer 3 может работать с несколькими JSON-файлами настроек.

Основной профиль:

    %APPDATA%\Timer_3\profiles\user.json

Активный профиль запоминается в файле:

    %APPDATA%\Timer_3\active_settings.json

### Выбор существующего профиля

Нажмите кнопку выбора рядом с полем **Файл с настройками** и выберите JSON-файл. Его значения немедленно загружаются в окно настроек.

### Создание нового профиля

Введите новый путь в поле файла настроек. Если расширение не указано, приложение добавит .json. Отсутствующий файл будет создан со значениями по умолчанию.

### Повреждённый или недоступный файл

Приложение не прекращает запуск из-за повреждённого профиля. Оно:

1. показывает предупреждение;
2. заменяет недостоверные значения значениями по умолчанию;
3. продолжает работу с безопасной конфигурацией.

Подробная схема файла: [SETTINGS.md](SETTINGS.md).

## Управление с клавиатуры

После заполнения двухзначного поля фокус автоматически переходит к следующему элементу. Клавиша Tab проходит только по элементам, относящимся к выбранному режиму.

На пустой вкладке обычного таймера начальный фокус устанавливается на ввод минут в паре минуты + секунды. После восстановления заполненного времени фокус устанавливается на кнопку **Пуск**.

## Решение проблем

### Нет голоса

- проверьте системную громкость;
- убедитесь, что в Windows установлен русскоязычный голосовой движок;
- закройте программы, которые могут удерживать аудиоустройство;
- перезапустите Timer 3.

### Не воспроизводится финальная мелодия

- проверьте существование выбранного MP3-файла;
- выберите файл с коротким путём без сетевых зависимостей;
- проверьте устройство вывода звука;
- верните встроенную мелодию: _internal/default.mp3.

### Настройки не сохраняются

Проверьте права на запись в каталог выбранного JSON-файла. Для обычной работы рекомендуется основной профиль в %APPDATA%.

### Приложение не запускается из исходников

Проверьте виртуальное окружение и зависимости:

    .venv\Scripts\python.exe --version
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    .venv\Scripts\python.exe -m pip install -e .

Для разработки используйте Python 3.13.
